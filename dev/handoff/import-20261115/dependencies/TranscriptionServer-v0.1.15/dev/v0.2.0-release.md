# TranscriptionServer v0.2.0

- 既定ページをサーバー管理画面へ変更し、文字起こしを `/transcribe` へ移動しました。既存APIは同じ8769番/protocol3を維持します。
- 信頼LANからモデルの導入・ロード・アンロード・状態確認・操作中止が可能です。WhisperとネイティブASRの常駐ロードを実認識へ再利用します。補助VAD/話者分離は処理時にロード・解放します。
- 同梱Web画面のキーなしLAN接続が未接続のままになる判定を修正しました。
- 旧既定データ保存先をTranscriptionServerへ安全に移行します。旧データはバックアップとして保持し、明示の別保存先は変更しません。
- FP16限定のGPU判定を修正し、Quadro M4000などのFP32候補を検出できます。ドライバー/CUDA環境の整合と実機受入は別途必要です。

PythonはWhisper専用ワーカーだけで使用します。FFmpeg/FFprobe、ネイティブモデル利用時のspeech.cppは別途準備してください。重みは同梱しません。未署名のWindows x64インストーラーです。詳細はdocs/model-management.mdを参照してください。

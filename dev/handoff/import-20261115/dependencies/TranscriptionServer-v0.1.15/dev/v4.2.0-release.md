# TranscriptionServer v4.2.0

- Windows x64・ユーザー単位のインストーラーを追加しました。録音・字幕・設定はプログラムの外へ保存し、アンインストール後も保持します。
- 非公開GitHubの最新安定版を起動後と24時間ごと、または手動で確認できます。更新用トークンはWindows資格情報または環境変数で保持します。
- アプリ内で確認して自己更新・再起動できます。処理中の録音がある場合は適用しません。取得ファイルのSHA256検証、旧版バックアップ、起動確認、適用失敗時の旧版復旧を追加しました。
- 既存のprotocolVersion=3、文字起こし/話者識別API、字幕・保存データは維持します。

推奨ファイルは `TranscriptionServer-v4.2.0-setup-x64.exe` です。ZIP版とソース版は自己更新の適用対象外です。インストールと更新の詳細は同梱の `docs/installation-updates.md` を参照してください。

PythonとWhisper CPUランタイムを同梱します。モデル、FFmpeg/FFprobe、speech.cpp、GPU用CUDAは別途必要です。インストーラーは未署名です。初回取得と自動更新の確認には非公開リポジトリを読めるアカウント/トークンが必要です。

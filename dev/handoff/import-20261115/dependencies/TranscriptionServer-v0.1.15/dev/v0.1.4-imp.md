# v0.1.4 実装計画・報告

## 設計（実装前）

v0.1.3からユーザー指定のv0.1.4へ更新する。処理方法の自動選択方針は変更しない。

- キュー投入queuedAt、枠取得dequeuedAt、GPU排他取得後の実処理開始startedAt、終了finishedAtを記録する。queueSecondsとresourceWaitSecondsを分離し、合計waitSecondsを返す。runSecondsは前処理・モデル取得/ロード・ASR・話者分離・結果確定を含み、アップロードと待機は含めない。
- timingVersion=1のmetadataとして秒数をSQLiteへ終端状態で保存する。読取時のみ計測中の秒数とtimingMeasuredAtを投影し、ポーリングでDBを更新しない。完了・中止・エラーは停止時点で固定する。正常停止はinterrupted、強制終了後の復旧は最終更新時点までの下限推定として扱い、停止中の時間を加算しない。
- 旧ジョブは確実な開始/終了時刻から取得できる値だけを推定し、不明はnullとする。旧resourceWaitSecondsには前処理も含まれていたため新計算に流用しない。
- 同梱文字起こし画面、履歴を開いた画面、管理画面の処理欄へ時間を表示する。ブラウザー時計のずれに依存せず、APIの測定値を単調時計で補間する。ブラウザー内認識とJSON保存でも同じ時間項目を扱う。
- docs/operations.mdの実装されていないrunSeconds/finishedAtの記載、およびCPUスレッド/ネイティブモデル再利用の記載を現実装に合わせる。GPU選択と比較の限界を資料に残す。

## フェーズ・検証

1. API/保存: 時間の純粋計算、終端固定、履歴・一覧・再起動、キュー/GPU待機、中止/エラー、旧データのテスト。Rust fmt/test/clippy後コミット。
2. UI/資料/版: 表示・補間・履歴/JSON・ブラウザー認識のテスト、隔離HTTPジョブと画面確認。関連資料とクライアント連絡後コミット。
3. 配布: クリーンなコミットからWindowsインストーラー/ZIP/ソース/SHA256を作成し、非公開GitHubのタグ・BUILD・資産を照合する。通常8769、AI Room依存18769/18770、別PCは停止・更新しない。

## 結果

M4000実機の比較ジョブ/ログは取得できていないため、実測の速度・精度差の原因は未確定。

### フェーズ1
- 時間計測と読取投影、全終端での保存、正常停止/異常再起動の区別を実装。既存HTTP再読込テストで終端timingMeasuredAtが変化する問題を検出し、finishedAtへ固定して修正。
- cargo test --locked --offline: 28件成功。cargo fmt、clippy全ターゲット -D warnings成功。Windows専用一時資格情報試験も成功。GPU待機分離は純粋計算試験であり実GPU受入ではない。

### フェーズ2

- v0.1.4へCargo/lock/package/HTML/READMEの版を統一。文字起こし画面の時間欄、管理画面の処理欄、稼働情報、JSON保存/インポート、ブラウザー内認識の時間を追加。旧履歴の推定・欠落、接続停止時の最終値、ジョブ切替を扱う。
- Rust28/Web102/Whisper2件成功、fmt/clippy -D warnings成功。HTTPのGPU排他をfixtureで保持して、実行開始前のrunSeconds=0とresourceWaitSecondsの増加を確認（GPUデバイスの実推論ではない）。
- 専用loopback48000/独立データでNemotron ASRの実C++/CPU認識を実行。23.254438秒の合成日本語2件、1件目run=4.198/queue=0.001秒、2件目run=4.285/queue=4.194秒。待機中中止はrun=0、無効メディアはerror/終了時刻を保存。SQLite生payload、非ページ/ページ一覧、終了/再起動後のmetadata完全一致を確認。証拠はServices/runtime/transcription-timing-0.1.4-debug/result.json。
- 隠しIABで履歴を開き、所要4秒/待機4秒/内訳を視認。ダウンロードしたJSONのrunSeconds=4.285/waitSeconds=4.194/finishedAtとAPIを照合。画面は同フォルダーcompleted.png。ダウンロードは合成字幕のみ。
- docs/operations.mdの未実装だった時間項目、resourceWaitSecondsの範囲、CPUスレッドとネイティブ常駐の説明、インストーラー名/旧番号の資料不一致を修正。docs/gpu-execution.mdにコードで確認したauto=cpu、候補表記、Vulkan経路、比較不能な点を記録。速度/精度改善やGPU実機検証を完了としない。
- 登録済みTC/MV/AI Roomの3チャットへ新時間項目の意味とcapabilities.jobTimingを送信。連絡とアプリ側受入は別。本通知だけでアプリ変更/稼働切替は依頼していない。

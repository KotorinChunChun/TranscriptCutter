TranscriptionServer v0.1.11 / Rust CLI・HTTP/API / Windows x64

## 変更点

- Rust本体がTLS1.2/1.3のHTTPSに対応。`--tls-cert` / `--tls-key` または保存設定から既存のサーバー証明書を参照します。同じポートで既存HTTPと併用でき、`--https-only`で平文を拒否できます。証明書は自動生成しません。証明書の対象名に合うHTTPS URLを案内し、既存の信頼LAN・接続キー不要/Bearer・Host/Origin・管理権限を維持します。
- 管理画面に「すべて導入／すべて削除」を追加。対象を固定して順に処理し、既導入・対象外を除外します。削除は確認したモデルだけが対象で、ロード中のモデル・録音・字幕・設定・実行環境を保持します。19GBのNemotron一体型は現PCでは導入・実行しません。
- 導入開始の確認を省略。対象行にアニメーションと取得元の実進捗を表示します。転送量はMiB、Whisperのファイル件数進捗は区別し、進捗未通知の旧ワーカーや展開・点検中は不定表示とします。
- 進捗と実際に必要な再起動通知だけを上部固定し、完了・失敗は各モデル行へ表示。反映待ちの実行環境/モデル名を列挙し、該当モデル行にも再起動を案内します。重みの取得だけで再起動を要求しません。
- 各モデルのCPU参考速度・フィラー出力傾向の計測データを更新。測定CPU・条件・版・処理時間の内訳は設定画面で確認でき、接続先PCの速度保証とは区別します。通常幅の再起動ボタンは「サーバーを再起動」、狭い画面では「再起動」と表示します。

## 配布と接続

setup、program-only Windows ZIP、source ZIP、SHA256SUMS.txtを提供します。モデル・認識ランタイム・Whisper用Python・FFmpeg/FFprobe・CUDA・CA/サーバー証明書・秘密鍵は同梱しません。認識ランタイムとモデルは必要に応じて管理画面から導入します。

protocolVersion=3と認識/ジョブ/話者分離APIを維持し、モデル情報APIのschemaVersion=1も変更しません。HTTPSは任意設定で、未設定の別PCは従来HTTPのままです。本PCの基本サーバーはHTTPS/HTTP併用へ更新済みですが、利用アプリ専用インスタンスは自動更新しません。クライアント側でHTTPSへ移行するときは、利用PCへ共通RootCAの公開CERだけを信頼登録し、サーバー証明書のSANと接続先を照合してください。既存HTTP接続の変更は必須ではありません。

同梱docs/https-and-client-certificates.mdに配布・登録・PC増設/移転の手順があります。既存共通証明書はWindows/Node/本PCブラウザーで検証済みですが、Python3.14既定の厳格検証ではAuthority Key Identifier不足で拒否されます。検証を無効化せず、必要な環境では証明書管理担当に同CAでの適合証明書更新を依頼してください。

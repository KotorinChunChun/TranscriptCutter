TranscriptionServer v0.1.8 / Rust CLI・HTTP/API / Windows x64

## 変更点

- 管理画面のモデルを用途別の枠・折り畳みに整理し、導入状態の色分け、RAM/VRAM・容量・速度/精度の参考値を表示。概算・公式参考・実測/未測定を区別します。
- 実行環境の検出と起動正常性を分離。破損した管理対象ランタイムを退避付きで修復し、反映に必要なサーバー再起動を案内します。外部配置は書き換えません。
- 処理方法の初期値を自動にし、再描画後も選択を保持。アンロードは選択枠だけを解放し、不要な常駐操作や導入状態不明時の誤警告を整理しました。
- 個別ジョブ削除API、sourceSha256/sourceBytes、対応FSでの同一媒体ハードリンク共用を追加。1参照を削除しても他ジョブの媒体を保持し、SQL確定失敗・プロセス異常終了時の復元/清掃を実装しました。
- Nemotron一体型30BのCPUアダプターを含みますが、19GBモデルは現PCでは導入・実行しません。既定enable_integrated_model=falseでUI/APIとも無効です。小型Nemotron ASRやNemotron話者分離とは別です。

## 配布・連携

setup-x64.exe、program-only Windows ZIP、source ZIP、SHA256SUMS.txtを提供します。認識ランタイム・FFmpeg/FFprobe・Python・モデルは同梱せず、管理UIから必要なものをオンライン導入します。PythonはWhisper認識専用です。

protocolVersion=3を維持。利用アプリはhealthのcapabilitiesと/v1/modelsの実行候補を確認してください。管理一覧全件を実行候補にしません。sourceSha256/sourceBytesは受信バイナリの指紋で、元動画を変換して送った場合は変換後の値です。旧ジョブの未知値は補完しません。CLI分離起動・認証・話者分離・媒体整理の詳細は同梱docs/embedding-contract.mdとdocs/operations.mdを参照してください。

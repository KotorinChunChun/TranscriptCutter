# TranscriptionServer v0.1.15

<!-- transcription-server-runtime:rust -->

- 保存済みのローカル未完了ジョブを、再起動後に同じIDで先頭から自動再実行します。旧字幕・計測を退避し、結果世代を更新して字幕の重複を防ぎます（最大3回）。
- 更新・停止時は新規受付を止め、受付済みの転送・待機・処理・ワーカー終了を待って正常終了します。新規要求には503とRetry-After: 5を返します。
- 管理画面に確認付きの正常停止と完了待ち取消を追加しました。インストーラーも対象プロセスを照合して正常停止し、停止できなければ上書きしません。
- インストーラーには従来と同じexampleDev-Test開発者署名とタイムスタンプを付けています。モデルと実行環境は配布物に含みません。

クライアントはjob.metadata.resultGenerationと字幕ページresultGenerationが変わったら、旧字幕とafterカーソルを破棄してafter=0から取得してください。TranscriptCutter候補との隔離Web試験で強制終了・復旧・重複なし・503待機表示を確認済みです。利用アプリの正式版反映は各担当で行います。

アップロード途中の再送、停止中のライブ音声復元、途中区間からの再開、有料外部APIの自動再課金は対象外です。入力破損・未保存・自動復旧上限超過は要確認として残します。

検証: Rust76件、Web18件、fmt/clippy、専用プロセスの異常終了/再実行、実Whisper TinyのCPU再実行、TranscriptCutter候補との通し試験。OS電源断と別PCの長時間負荷試験は含みません。

通常の導入にはsetup-x64.exeを使用してください。HTTPS・接続先・既存データ/設定/モデルを維持して更新できます。旧版へ連続要求が届く場合はクライアントからの新規送信を一時停止してください。

TranscriptionServer v0.1.10 / Rust CLI・HTTP/API / Windows x64

## 変更点

- 本体のWeb画面をサーバー管理専用に整理しました。同梱の文字起こし画面と `/transcribe` は廃止し、文字起こし操作はTranscriptCutterなどの利用アプリから従来のAPIを使います。
- 固定ヘッダーへ表示切替と確認付きの再起動を集約し、「設定・更新」ポップアップから更新確認・適用・GitHub接続設定を操作します。更新管理の同PC限定は維持します。
- 用途別・折り畳み一覧を整理。状態列を除き、導入/削除ボタンで導入状態を表現します。各モデルの操作を「モデル: 導入/削除」「ファイル処理: CPU/GPU/アンロード」「リアルタイム: CPU/GPU/アンロード」に統一しました。処理時ロード/解放型の補助モデル等には常駐操作を表示しません。
- 簡易表示にもRAM/VRAM概算上限を表示し、狭い画面では容量・RAM・VRAMをモデル名の下へまとめます。保存容量はGB、転送進捗は従来のMiBです。詳細表示は略式情報の重複を除き、全詳細と同じ操作を表示します。
- 旧版のCPU実測に基づく参考速度と、測定CPU・版・条件を表示します。未測定は未測定表示。異なる条件での参考値で、現在の接続先PCの速度保証や同条件比較ではありません。
- 読取専用 `GET /api/models` で管理対象15モデルの保有状態・利用可否・4用途の概要/入出力・容量/RAM/VRAM・条件付き参考速度を返します。`health.capabilities.modelInformation` と `modelInformationUrl` で検出でき、既存 `/v1/models` の該当行にも `x_meeting.modelInfo` を追加します。UI/APIは説明データを共通化しました。
- 非共有インスタンスのHF_HUB_CACHEも専用キャッシュへ固定し、親環境の共有モデル先を引き継がないようにしました。共有インスタンスのモデル先は変更しません。

- 旧アップロードを点検/整理するRustのオフラインCLI `--compact-media --data-dir <絶対パス> [--apply]` を追加しました。以前の共用機能が対象にできなかった指紋未記録の旧ジョブを補完し、完全一致の媒体を同じ保存先内で共用します。起動中や未完了ジョブがある場合は拒否し、ジョブ・字幕・媒体のパスを保持します。

## 配布・連携

Windowsユーザー単位インストーラー、program-only Windows ZIP、source ZIP、SHA256SUMS.txtを提供します。認識ランタイム・Whisper用Python・FFmpeg/FFprobe・モデルは同梱しません。必要に応じて管理画面から導入します。

protocolVersion=3と認識/ジョブ/話者分離APIは維持します。モデル情報APIのschemaVersion=1は別の版です。モデル情報の全件を実行候補にせず、従来の `/v1/models` と各行の利用可否を参照してください。信頼LANの空キー接続と既存Bearer構成を維持します。19GB一体型は現PCでは導入・実行せず既定無効です。

## 検証と境界

隔離環境でTinyの私有コピーの削除、オフラインキャッシュによる導入、CPUロード/アンロード、再起動取消/実行・再接続・モデル保持を確認しました。AI Roomの独立クライアントで15モデル/4用途、旧CPU参考速度4件、未測定11件null、v1追加情報との一致、従来候補取得との互換性を確認しています。共有TinyのSHA256と既存3サーバーのPID/版は隔離確認の前後で一致しました。追加の実データ整理では8769だけを一時停止し、同じv0.1.8と設定へ復帰しました。48ジョブ・16552字幕・48媒体の内容を保持して9.78GBを削減しました。

物理別PC/LAN、GPU/M4000、新規オンライン導入、全モデル認識・速度、インストーラー実適用・自己更新実適用、クライアント画面への概要/速度表示は未確認です。インストーラー署名は未設定です。本リリース作業で稼働サーバーへ適用しません。完成済みのコード整理も含みます。PC別速度の自動更新・モデル最終点検時刻の追加は含めていません。

# TranscriptionServer v0.1.0

- CLI・HTTP/API・SQLiteジョブ管理・自己更新をRustへ移行。Pythonは同梱のWhisper認識ワーカーだけで使用します。
- プライベートLAN接続を標準化し、接続キーの手入力を不要にしました。起動時に接続用IPv4・サブネット・モデルの導入状況を表示します。
- 既存のジョブID・字幕・録音とAPI protocolVersion=3を保持します。ネイティブ話者分離、ファイル/リアルタイム枠、字幕編集、Range再生に対応します。
- Windowsユーザー単位インストーラーでPython版v4.2.0から移行できます。バージョン番号はユーザー指定によりv0.1.0から開始します。
- 非公開GitHub Releaseの更新確認・SHA256検証・プログラム/DBバックアップ・適用後の起動確認と失敗復元をRustで実行します。旧Python世代を更新先と誤認しません。

Windows x64向けです。WhisperワーカーはPython環境を同梱し、Pythonの別途インストールは不要です。FFmpeg・speech.cpp・モデルの用意はREADMEを参照してください。LANのファイアウォール許可は管理者権限で対象を限定して設定します。

モデル重みの導入点検と実音声/GPUの動作保証は別です。物理的な別PC・GPU・長時間の実会議音声は別途受入が必要です。非公開Releaseの更新確認には読取権限のあるGitHub資格情報を設定してください。

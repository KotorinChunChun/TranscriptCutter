# TranscriptionServer v0.1.12

- 起動時に不足するWhisper専用環境、speech.cpp、NeMo-Speech.cpp、FFmpeg/FFprobeを自動導入します。モデル本体は自動取得しません。
- 準備中も管理HTTP・PID記録・進捗を提供し、healthのstartupState/acceptingJobsで管理画面の起動と認識受付を区別します。初回導入を起動失敗と誤判定する問題を修正しました。
- 実行環境の導入・修復後は同じプロセスへ反映し、手動再起動が不要になりました。
- 管理画面に実行環境ごとの状態・容量と合計を追加しました。実測、外部配置の未集計、新規導入の参考容量を区別します。
- Windowsの長いnativeモデル保存パスと混在する区切り文字を修正しました。Nemotron一体型は--enable-integrated-modelで明示有効化できます。約19GBのモデルは既定無効・自動取得対象外です。

protocolVersion=3、認識API、LAN認証、HTTPS/同ポートHTTP互換、ジョブ・字幕形式は維持します。組込みアプリは準備中の新規認識を待機し、既存の準備済みモデル一覧を使ってください。オフライン/開発用には--no-auto-runtimesを指定できます。

隔離環境で実パッケージ4種類の初回取得、同PID反映、失敗後修復、候補setupの新規/0.1.11からの更新と専用データ保持を確認しました。Rust全体64件と追加回帰1件、Web15件、fmt/clippy成功。Core i5-12500T/32GB/CPU8スレッドで19GB IQ4_NLモデルの23.25秒合成日本語2話者を約35.13秒で処理し、6時刻付き区間/2話者を確認しました。長時間実録音の精度や共通ベンチマーク結果を保証する試験ではありません。M4000実機はユーザー確認済みです。

配布物は本体・Web管理画面・資料のみ。実行環境・モデル・CUDA/ドライバー・CA公開証明書・秘密鍵・設定・録音・資格情報は同梱しません。本PCの稼働版更新は今回のリリース作業に含めません。

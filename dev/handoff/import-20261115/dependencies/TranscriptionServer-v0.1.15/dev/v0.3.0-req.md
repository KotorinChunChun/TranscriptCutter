# v0.3.0 要求定義書

- [x] AI Roomからの依頼により、ASRを呼ばずNemotron 3 Diarizationだけを実行するジョブAPIを追加する。
- [x] protocolVersion=3と既存API・録音・字幕・ジョブIDを保持する。
- [x] 元メディア秒の話者区間、speakers配列、空text、話者分離状態・モデル・実デバイスを返す。
- [x] モデル一覧へ単独分離のtaskと能力・導入状況を広告し、未導入時に別モデルの代替や無断取得を行わない。
- [x] 無音・中止・キュー・既存モデル互換と、可能な場合は合成音声のCPU実処理を検証する。
- [x] Nemotron 3.5 Transcribeを分離専用モデルと区別し、未設定・条件不足なら取得せず利用不可の能力と理由を返す。
- [ ] 安全に反映できる場合だけ本PC8769へ反映し、実配備と未確認事項を区別して報告する。
- [x] 別チャットへ返信せず、このチャットの最終回答へ確定API・版・試験結果を残す（依頼元からの追加連絡）。
- [x] 8769の処理を維持し、AI Room接続試験用のloopback候補を別ポート・別データで起動し、接続情報を報告して検証終了まで残す（追加依頼）。

8769反映は既存ジョブ実行中のため保留。追加依頼でも稼働ジョブを止めないよう指定されている。

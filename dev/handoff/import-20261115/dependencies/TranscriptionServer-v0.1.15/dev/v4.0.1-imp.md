# v4.0.1 実装計画・報告書

本版はServices/dev/v0.20261111.1-imp.mdの統合作業中に必要となったWhisper実行環境の互換修正。事前計画・判断経緯・実通信結果は同資料を正本とする。

- faster-whisper 1.2.1 + PyAV 19.0.2は音声デコード時にmetadata_errorsで失敗することを実認識で確認。PyAV 18.1.0では成功したが、既存Python3.10対応を保持するためPyAV16.0.1を最終採用。faster-whisper/CTranslate2は既存の固定版を保持。
- requirements-whisper.txtへ固定版を追加し、setup-whisper.ps1にモデル取得不要のWAVデコード検査を追加。site-packagesや上流コードを直接書き換えていない。
- 本PC（Python3.12.14）でsetupのデコード検査成功、合成日本語音声のTiny/CPU実認識成功。既存Python試験63件中62件成功・1件skip。
- Python3.10での実導入、GPU、長時間録音、話者分離の受入は未確認。UI・認識APIの仕様は変更していない。

# v0.1.1 要求定義書

- [x] 修正ごとにEXEを作成せず、まずWebブラウザーで動く確認版をできるだけ素早く表示する。
- [x] ブラウザーで動くWhisperだけは各ツールで個別に導入できるようにする。
- [x] サーバー側の導入・モデル管理・工程時間/メモリ記録の修正指示をサーバー担当セッションへ送る。
- [x] 認識範囲を「先頭・カスタム hh:mm:ss.sss」「末尾・カスタム hh:mm:ss.sss」で指定でき、末尾指定で端数を落とさない。
- [x] サーバーが未対応・導入不能のモデルを候補に表示しない。
- [x] モデルを切り替えても話者分離の選択を維持する。
- [x] 現在時刻の表示をやめ、進捗に基づく終了見込みを表示する。
- [x] 各処理工程の所要時間と、取得可能な場合の消費メモリを処理記録に残す。

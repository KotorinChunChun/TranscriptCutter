# v0.1.1 要求定義書

- [ ] ブラウザーで動くWhisperだけは各ツールで個別に導入できるようにする。
- [x] サーバー側の導入・モデル管理・工程時間/メモリ記録の修正指示をサーバー担当セッションへ送る。
- [ ] 認識範囲を「先頭・カスタム hh:mm:ss.sss」「末尾・カスタム hh:mm:ss.sss」で指定でき、末尾指定で端数を落とさない。
- [ ] サーバーが未対応・導入不能のモデルを候補に表示しない。
- [ ] モデルを切り替えても話者分離の選択を維持する。
- [ ] 現在時刻の表示をやめ、進捗に基づく終了見込みを表示する。
- [ ] 各処理工程の所要時間と、取得可能な場合の消費メモリを処理記録に残す。

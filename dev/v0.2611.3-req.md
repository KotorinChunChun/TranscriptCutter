# v0.2611.3 要求定義書

- [x] 信頼LANモードのサーバーURLをキー空欄で指定し、healthで認証方式を自動判別して一時トークンで認識・字幕編集・中止を利用できるようにする。
- [x] Bearer構成は任意のキー入力を残し、401時に必要な設定を表示する。
- [x] 別アプリ・リダイレクト先へキーを転送せず、キーをJSONファイルやlocalStorageへ保存しない。
- [x] 現在の機能・動画・保存データを保持し、接続先の自動フォールバックは追加しない。
- [ ] 模擬応答でLAN・Bearer・旧ローカルとキー非転送を回帰確認し、サーバー準備完了後に実LAN IPで接続試験を行う。
